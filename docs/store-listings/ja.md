## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Textは、どんなテキストも声に出して読み上げます。画面を見つめる代わりに、耳で聞くことができます。

Windowsではタスクトレイに常駐します。ほとんどのアプリでテキストを選択するかコピーすると、すぐに読み上げます。Ctrl+Win+Rを押すと、コピーした内容を読み上げます。(ターミナルは選択範囲を通知しないので、テキストをコピーしてください。)

Androidでは、テキストを貼り付けるか入力する、.txt、.pdf、.docxファイルを開く、またはカメラでページをスキャンして、再生をタップします。

- お使いの端末上で動く自然な音声
- 読み上げ速度は0.5倍から2倍
- 音声パックをダウンロードすればオフラインで使えます(初回起動時の一度だけのダウンロード)。テキスト、ファイル、スキャンが端末の外に出ることはありません
- アカウント不要、広告なし
- テキスト、名前、識別子を含まない匿名の利用回数カウントは任意で、設定でいつでもオフにできます

## Google Play only: download note (append to the full description)

Androidで初めてアプリを起動すると、約145MBの音声パックをダウンロードするため、一度だけインターネット接続が必要です(Wi-Fi推奨)。ダウンロードが終わるまでは、スマートフォン内蔵の音声で読み上げます。スキャンでは、お使いの言語用の小さな文字認識パックもダウンロードします。ダウンロードされるのはこれらのパックだけです。テキスト、ファイル、スキャンは端末の中にとどまり、音声のインストール後は、読み上げにネットワークを使いません。ほかにネットワークを使うのは、任意の匿名の利用回数カウントとクラッシュレポートだけで、設定でオフにできます。

## Microsoft Store only: download note (append to the full description)

Windowsで初めてアプリを起動すると、お使いの言語の音声パック(最大約150MB)をダウンロードするため、一度だけインターネット接続が必要です。ダウンロードが終わるまでは、Windows内蔵の音声で読み上げます。ダウンロードされるのはパックだけです(音声と、使う場合は翻訳)。テキストとファイルは端末の中にとどまり、音声のインストール後は、読み上げにネットワークを使いません。ほかにネットワークを使うのは、新しいバージョンの毎日の確認と、任意の匿名の利用回数カウント(アプリ自身が対処した問題、たとえば別の音声への切り替えの通知も含みます)だけで、カウントは設定でオフにできます。
