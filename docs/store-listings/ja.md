## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Text は、あらゆるテキストを声に出して読み上げます。画面を見つめる代わりに、耳で聞けます。

Windows ではタスクトレイに常駐します。ほとんどのアプリでテキストを選択またはコピーすると、すぐに読み上げます。Ctrl+Win+R でコピーした内容を読み上げます。（ターミナルは選択を通知しないため、テキストをコピーしてください。）

Android では、テキストを貼り付けるか入力するか、.txt・.pdf・.docx ファイルを開くか、カメラでページをスキャンして、再生をタップします。

- お使いのデバイス上で動作する自然な音声
- 読み上げ速度は 0.5倍～2倍
- オフラインで動作（Android では初回起動時に音声を一度だけダウンロード）：テキスト、ファイル、スキャンはデバイスの外に出ません
- アカウント不要、解析なし

## Google Play only: download note (append to the full description)

Android で初めてアプリを起動すると、約 145 MB の音声パックをダウンロードするため、インターネット接続が一度だけ必要です（Wi-Fi を推奨）。ダウンロードが完了するまでは、スマートフォン内蔵の音声で読み上げます。ダウンロードされるのは音声パックのみです。テキスト、ファイル、スキャンはデバイス上に残り、音声のインストール後はネットワークを使用しません。
