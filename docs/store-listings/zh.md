## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Text 可以把任何文字朗读出来，让你用听代替盯着屏幕看。

在 Windows 上，它常驻系统托盘。在几乎任何应用中选中或复制文字，就会立即朗读。按 Ctrl+Win+R 可朗读刚复制的内容。（终端不会报告选中的文字，请在终端中复制文字。）

在 Android 上，粘贴或输入文字，打开 .txt、.pdf 或 .docx 文件，或用相机扫描一页纸，然后点击播放。

- 在你的设备上运行的自然语音
- 朗读速度 0.5 倍至 2 倍
- 离线可用（Android 版首次启动时下载一次语音）：你的文字、文件和扫描内容不会离开设备
- 无需账号，无数据分析

## Google Play only: download note (append to the full description)

在 Android 上首次启动应用时，会下载约 145 MB 的语音包，因此需要联网一次（建议使用 Wi-Fi）。下载完成之前，应用会使用手机自带的语音朗读。只会下载语音包。你的文字、文件和扫描内容始终保留在设备上，语音安装完成后，应用不再使用网络。
