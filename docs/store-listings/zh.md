## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Text 可以朗读任何文本，让您用听代替盯着屏幕。

在 Windows 上，它常驻系统托盘。在几乎任何应用中选中文本或复制文本，就会立即朗读。按 Ctrl+Win+R 朗读您刚复制的内容。（终端不会报告选区，请在终端中复制文本。）

在 Android 上，粘贴或输入文本，打开 .txt、.pdf 或 .docx 文件，或用相机扫描一页，然后点按播放。

- 在您的设备上运行的自然语音
- 朗读速度 0.5 倍到 2 倍
- 语音包下载后可离线使用（首次启动时一次性下载）；您的文本、文件和扫描内容绝不会离开您的设备
- 无需账号，没有广告
- 可选的匿名使用统计，不含文本、姓名或标识符；可随时在“设置”中关闭

## Google Play only: download note (append to the full description)

首次在 Android 上启动应用时，它会下载约 145 MB 的语音包，因此需要联网一次（建议使用 Wi-Fi）。下载完成前，应用使用手机内置语音朗读。扫描还会下载适用于您的语言的小型文字识别包。只会下载这些包：您的文本、文件和扫描内容都留在您的设备上，语音安装后，朗读不使用网络。唯一的其他网络用途是可选的匿名使用统计和崩溃报告，您可以在“设置”中关闭。
