## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Text читает вслух любой текст, чтобы вы могли слушать, а не смотреть в экран.

В Windows приложение живёт в области уведомлений. Выделите текст почти в любой программе или скопируйте его, и он сразу прозвучит. Нажмите Ctrl+Win+R, чтобы прочитать скопированное. (Терминалы не сообщают о выделении, поэтому там копируйте текст.)

В Android вставьте или введите текст, откройте файл .txt, .pdf или .docx либо отсканируйте страницу камерой, затем нажмите воспроизведение.

- Естественно звучащие голоса, работающие на вашем устройстве
- Скорость чтения от 0,5x до 2x
- Работает офлайн после загрузки пакета голоса (одна загрузка при первом запуске); ваши тексты, файлы и сканы никогда не покидают устройство
- Без учётной записи и без рекламы
- Необязательный анонимный подсчёт использования без текста, имён и идентификаторов; его можно отключить в любой момент в Настройках

## Google Play only: download note (append to the full description)

При первом запуске на Android приложение загружает пакет голоса примерно на 145 МБ, поэтому один раз нужно подключение к интернету (лучше по Wi-Fi). Пока загрузка не завершена, приложение читает встроенным голосом телефона. Сканирование также загружает небольшой пакет распознавания текста для вашего языка. Загружаются только эти пакеты: ваши тексты, файлы и сканы остаются на устройстве, а после установки голоса чтение не использует сеть. Единственное другое использование сети — необязательный анонимный подсчёт использования и отчёты о сбоях, которые можно отключить в Настройках.

## Microsoft Store only: download note (append to the full description)

При первом запуске в Windows приложение загружает пакет голоса для вашего языка (до 150 МБ), поэтому один раз нужно подключение к интернету. Пока загрузка не завершена, приложение читает встроенным голосом Windows. Загружаются только пакеты (голос и, если вы им пользуетесь, перевод): ваши тексты и файлы остаются на устройстве, а после установки голоса чтение не использует сеть. Единственное другое использование сети — ежедневная проверка наличия новой версии и необязательный анонимный подсчёт использования, который также передаёт сообщения о проблемах, с которыми приложение справилось само (например, переход на другой голос); подсчёт можно отключить в Настройках.

## App Store description (<= 4,000)

Read The Stupid Text читает вслух любой текст, чтобы вы могли слушать, а не смотреть в экран.

Вставьте или введите текст, откройте файл .txt, .pdf или .docx либо отсканируйте страницу камерой, затем нажмите воспроизведение. Каждое предложение подсвечивается во время чтения.

- Естественно звучащие голоса, работающие на вашем iPhone или iPad
- Скорость чтения от 0,5x до 2x
- Работает офлайн после загрузки голоса; ваши тексты, файлы и сканы никогда не покидают устройство
- Необязательный перевод на устройстве (по умолчанию выключен)
- Без учётной записи и без рекламы
- Необязательный анонимный подсчёт использования без текста, имён и идентификаторов; его можно отключить в любой момент в Настройках

При первом открытии приложение загружает голос для вашего языка, примерно 145 МБ, поэтому один раз нужно подключение к интернету (лучше по Wi-Fi). Пока загрузка не завершена, приложение читает встроенным голосом устройства. Сканирование также загружает небольшой пакет распознавания текста для вашего языка. Загружаются только эти пакеты: ваши тексты, файлы и сканы остаются на устройстве, а после установки голоса чтение не использует сеть.

Read The Stupid Text есть также для Windows (утилита в области уведомлений, которая читает то, что вы выделяете или копируете) и для Android.
