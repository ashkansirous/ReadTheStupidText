## Long description (Microsoft Store <= 10,000 chars; Google Play <= 4,000)

Read The Stupid Text lit n'importe quel texte à voix haute : écoutez au lieu de fixer l'écran.

Sous Windows, l'application vit dans la zone de notification. Sélectionnez ou copiez du texte dans presque n'importe quelle application et il est lu aussitôt. Appuyez sur Ctrl+Win+R pour lire ce que vous venez de copier. (Les terminaux ne signalent pas les sélections : copiez le texte.)

Sous Android, collez ou saisissez du texte, ouvrez un fichier .txt, .pdf ou .docx, ou scannez une page avec l'appareil photo, puis appuyez sur lecture.

- Des voix naturelles qui fonctionnent sur votre appareil
- Vitesse de lecture de 0,5x à 2x
- Fonctionne hors ligne : vos textes, fichiers et scans ne quittent jamais votre appareil
- Aucun compte, aucune analyse d'usage
