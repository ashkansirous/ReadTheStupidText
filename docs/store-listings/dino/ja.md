## Description

Dino Book Readerは、3歳から9歳のお子さま向けに、絵本のお話を読み聞かせるアプリです。登場人物ごとに違う声で読み上げます。語り手がお話を進め、オオカミ、子ブタたち、ジンジャーブレッドマンがそれぞれの声で話します。

お話を選ぶ
おとなの方が、おはなしの本棚から本を選びます。やさしく語り直した昔ながらの童話で、どのページにも絵があります。4つのお話は無料です。どの本にも、選んだ言語のあらかじめ用意された声がついています。

家族の声でお話を
お父さん、お母さん、おじいちゃん、おばあちゃんが、どの登場人物のどのページでも、どの言語のお話でも、自分の声を録音できます。お子さまはあなたの読み聞かせを聞くことができ、録音は端末の中だけに保存されます。

いっしょに読む
- 読み上げている文が光るので、お子さまが目で追えます。
- 絵だけ、文字だけ、絵と文字の3つの表示から選べます。
- 読む速さは0.8倍から1.2倍まで。動物の音はオンとオフを切り替えられます。
- 寝る前のお話に合う夜のテーマがあります。

お話と価格
4つの絵本は無料です：ライオンとネズミ、ジンジャーブレッドマン、3びきのこぶた、Xが宝のしるし。本棚のそのほかのお話は1話0.99ドルです（Google Playにはお使いの通貨で価格が表示されます）。おとなの方がペアレンタルゲートの向こうで、Google Playを通じて一度購入すれば、以前の購入はいつでも復元できます。すでにお持ちのお話は端末に残ります。

15の言語
アプリ、お話、声は、英語、アラビア語、中国語、デンマーク語、オランダ語、ペルシャ語、フィンランド語、フランス語、ドイツ語、日本語、ノルウェー語、ポルトガル語、ロシア語、スペイン語、スウェーデン語で楽しめます。
