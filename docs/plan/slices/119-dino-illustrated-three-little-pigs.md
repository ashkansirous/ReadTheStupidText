# Slice 119 — Dino: illustrated Three Little Pigs, and the starters in the store

*Planned 2026-10-25.* Dino Reader only; RTST is not touched.

**Batch:** 25 (story illustrations)
**Depends on:** Slice 98 (starter pictures), Slice 92/102 (store build and upload)
**Touches:** `tests/DinoReader.Tests/Starters/three-little-pigs/**`, `tests/DinoReader.Tests/StarterBuilder.cs`, `tests/DinoReader.Tests/StoreBuilder.cs`, `tests/DinoReader.Tests/Store*Tests.cs`, `tests/DinoReader.Tests/Starter*Tests.cs`, `src/DinoReader.App/Resources/Raw/starters/three-little-pigs.dino`, `tools/prepare-story-pictures.ps1`, `tools/upload-store-story.ps1`, `docs/design/story-art/**`, `src/DinoReader.App/CLAUDE.md`, `src/DinoReader.Core/CLAUDE.md`

## Why

The store's stories are text only. The user wants a cover and a picture on every page. There is no
image API, only the Gemini web app. Doing it by hand means generating character sheets, downloading
them, opening a new chat and re-explaining the story for every page, which is too much work. Claude
drives Gemini in the user's signed-in Chrome instead. The user's thread
(https://gemini.google.com/app/5bdec8c40a5d27ba, "3 little pigs characters") already has a Pim sheet,
a Wolf portrait and sheet, and a line-up of Pip, Pop, Pim and Wolf. This slice finishes that book first,
as the pilot that proves the loop.

The user also wants the four bundled starters (Good Enough, The Three Little Pigs, The Gingerbread Man,
The Tortoise and the Hare) in the store, so anyone who deletes one can download it again.

## Decisions (2026-10-25, agreed with the user)

- **Decision 125: Claude illustrates the books by driving the Gemini web app in the user's Chrome.**
  The user approved, once and for all, saving Gemini's pictures into a working folder and committing
  them to the repo. One Gemini chat per book: character sheets and a line-up first, then the cover, then
  one picture per page in the same chat, so Gemini keeps the characters consistent. The free tier has a
  daily image cap: when Gemini refuses, stop and resume next day in the same chat.
- **Decision 126: one house style for every book.** "Children's picture book illustration, soft
  watercolour and coloured pencil, warm gentle colours, simple rounded shapes, no text". The exact
  style line and each book's character descriptions are kept in `docs/design/story-art/<stem>.md`.
- **Decision 127: pictures are 3:4 portrait with no text in them.** Upright, the picture fills the page
  and the text panel covers up to 58% from the bottom, so every page prompt asks for the characters and
  action in the top half. Covers are text-free; the title comes from our code, not from Gemini (it
  misspells, and one picture serves all 9 languages).
- **Decision 128: the bundled starters are also store stories, with the same package id.** A user who
  deleted one sees it in the store and downloads it back. The installed copy and the store copy are the
  same book.
- This reverses the Batch 10 out-of-scope item "Illustrations generated by AI" and supersedes the
  public-domain illustration follow-up of Slice 102 / Decision 106.

## Work

- [ ] **Art record.** Write `docs/design/story-art/three-little-pigs.md`: the style line, each
      character's description (Pip, Pop, Pim, Wolf, as in the thread; Mother Pig if the text has her),
      the cover prompt and one prompt per page (page text summarised into a scene, characters in the top
      half). Page count comes from `StarterTexts.Pigs` (pages split on `---`).
- [ ] **Generate in Gemini** (Chrome, the existing thread): set aspect ratio 3:4, finish any missing
      character sheets (Pip, Pop), then the cover, then pages 1..N. Check each against the line-up; redo
      any that drift (wrong colours, extra pig, text in the picture). Save the originals to a working
      folder outside the repo.
- [ ] **`tools/prepare-story-pictures.ps1 <source folder> <stem>`**: centre-crop to 3:4, resize to
      1080x1440, JPEG quality 85, write `tests/DinoReader.Tests/Starters/<stem>/pictures/1..N.jpg` and
      `cover.jpg`. Fails if the count doesn't match the page count it is given.
- [ ] **Starter build picks up the cover.** `StarterBuilder` uses `Starters/<stem>/cover.jpg` as a
      Picture cover when present (as Good Enough does), then rebuild with `DINO_BUILD_STARTERS=1` so
      `Resources/Raw/starters/three-little-pigs.dino` carries the pictures. Check the shelf, the store and
      the reader show the title over or beside a picture cover; if a picture cover hides the title
      anywhere, draw it there in the app.
- [ ] **Starters in the store.** `StoreBuilder` also writes the four starters to `artifacts/store/<id>/`
      (same package ids as the bundled files, `meta.json` with credits, ages, author, `version` one higher
      than anything uploaded before), with `cover.jpg` from the picture cover or `StoreCover.Render`.
      Upload all four with `tools/upload-store-story.ps1`.
- [ ] **Recover after delete.** Confirm on the emulator: delete The Three Little Pigs from the shelf, open
      the store, download it, and it reads with its pictures. If the store hides stories whose id is
      bundled, change that.
- [ ] Record the house-style and picture-size rules in `src/DinoReader.App/CLAUDE.md` (where pictures go,
      3:4 at 1080x1440, run the prepare script, never commit unresized originals).
