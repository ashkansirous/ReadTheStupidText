## Research: non-Latin page reading (2026-11-05, research only, for the user to pick)

Android, ML Kit Text Recognition v2 ([scripts](https://developers.google.com/ml-kit/vision/text-recognition/v2/languages), [setup](https://developers.google.com/ml-kit/vision/text-recognition/v2/android)): script models are Latin, Chinese, Japanese, Korean, Devanagari. **Farsi, Arabic and Russian (Cyrillic) are not supported by any ML Kit model.** Japanese and Chinese are.
- Bundled (`com.google.mlkit:text-recognition-chinese` / `-japanese`, 16.0.1): about 4 MB per script per architecture added to the app. MAUI binding: `Xamarin.Google.MLKit.TextRecognition.Chinese` / `.Japanese` 116.0.1.9.
- Unbundled (Google Play services, `com.google.android.gms:play-services-mlkit-text-recognition-chinese` / `-japanese`, 16.0.2): about 260 KB app-size increase per script per architecture; the model downloads on demand through Play services. Download size: not found. MAUI binding: `Xamarin.GooglePlayServices.MLKit.Text.Recognition.Chinese` / `.Japanese` 116.0.1.9. NuGet package sizes: not found.
- For Farsi, Arabic, Russian on Android the only route found is Tesseract (`tessdata_fast`, on-demand download; sizes from the files' Content-Length at github.com/tesseract-ocr/tessdata_fast): fas 0.43 MB, ara 1.43 MB, rus 3.86 MB, jpn 2.47 MB, chi_sim 2.47 MB (about 10.7 MB for all five; `tessdata_best` is 3.3 / 12.6 / 15.3 / 14.3 / 13.1 MB). Accuracy on camera photos versus ML Kit: not checked. Google Cloud Vision: not verified (server API, not on-device).
iPhone, Apple Vision `VNRecognizeTextRequest` ([supportedRecognitionLanguages](https://developer.apple.com/documentation/vision/vnrecognizetextrequest/supportedrecognitionlanguages(for:revision:)), [WWDC22 10024](https://developer.apple.com/videos/play/wwdc2022/10024/)): the supported list is read at run time per revision and recognition level; Japanese and Korean arrived with revision 3 (iOS 16). **Not found:** the iOS version that added Arabic, Persian, Russian or Chinese, the fast/accurate split, and any statement that Persian is supported (Apple's Live Text availability list names Chinese, Japanese and Russian, not Arabic or Persian; Live Text is not the Vision API). Vision is part of the OS, so no model ships in the app (not confirmed for every language). To settle it: call `supportedRecognitionLanguages(for: .accurate, revision: <newest>)` on the minimum iOS version's simulator or a device.
