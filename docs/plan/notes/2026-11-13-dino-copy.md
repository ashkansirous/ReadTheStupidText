# 2026-11-13 — Final app copy for the Onboarding and Missing States mocks

The user asked (2026-11-13, RefineScope) for the text on every screen of the two 2026-11-13 mocks
(`docs/design/dino-reader/Dino Reader 2026-11-13 Onboarding.dc.html` and `... Missing States.dc.html`) to be
refined into final app copy: short, plain, for parents, consistent with
`src/DinoReader.App/Resources/Strings/AppResources.resx` (and RTST's strings for its voice pack rows), reusing
existing strings where the meaning is the same. The canvas was updated with this copy the same day; this table is
the source for the string keys. **Existing** = key and text already on main; **New** = add it; **Changed** = same
key, new English text (translations redone). Every New or Changed string goes into all 15 `AppResources.<lang>.resx`
(and RTST's `.resx`/`.resw` languages for its rows); `NoHardCodedUiTextTests` enforces it.

Placeholders: `{0}` etc. as in .NET format strings. `**word**` is bold in the UI.
