## What went wrong in the runs

- The first run went behind a PIN lock: only the locked download could run. Unattended runs need the lock off.
- The first run deleted the `kokoro-en` pack to force a download, which blocked the Kokoro check.
- The second brief said "no taps", so every language item (Norsk, Swedish, Danish, German, Farsi, translation)
  came back "no hook" although the language is a setting in the app. Rule now: script the app's own UI
  through uiautomator (`tools/CLAUDE.md`, ClaudeSkills `device-test`). A `set-language` Debug hook would
  make these faster.
