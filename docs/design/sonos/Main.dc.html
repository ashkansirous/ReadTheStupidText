Dino on Sonos: the browse tree

Sonos draws every screen; Dino only answers with folders and tracks (title, subtitle, square art) and a search box. So the design is the tree: open in the parent’s own language, group by what a parent is choosing for (bedtime, age, new, free), and keep every other language one tap away.

Level 0 · first screen

Root, in the parent’s language

  • Language = first of the phone’s Accept-Language list that Dino has (fa-IR → Farsi)
  • Search box: Stories · All languages
  • 6 shelves, then the 2nd matched language as its own row (if any), then Other languages

No header or no match

  • A speaker or a controller that sends no language: root is the language list, as today (no guess)
  • A phone language Dino lacks (e.g. Italian): next language in the list, else English
→
Level 1 · shelves

Shelves (playable folders)

  • Bedtime: 10 min or less, shortest first
  • New: store tag New, newest first
  • Ages 3–5: ageMin ≤ 5 · Ages 6–9: ageMax ≥ 6 (a 3–9 book is in both)
  • Free: access = free
  • All, A–Z: that language’s alphabet, ignoring “The”
  • An empty shelf is hidden; Play on a shelf queues all of it

Other languages

  • 14 rows: own name, parent’s name for it + count underneath
  • Phone’s other languages first, then by name
  • Each opens the same root shelves in that language
→
Level 2 · books

Book = one playable track

  • Square cover (cropped from the portrait cover)
  • Title in the shelf’s language
  • Subtitle: age · minutes · Free / In the Dino app, in that language and its digits
  • Same book in another language = another track
Ids (why it sticks without settings)

The language lives in the id

  • lang:fa → root of Farsi
  • lang:fa/bedtime, lang:fa/age-3-5 …
  • track:fa:lion-and-mouse (today’s form)
  • A Sonos Favorite or queue keeps its language on a speaker that never sends a header

Open to decide

  • Paid books on an anonymous service: list them marked “In the Dino app”, hide them, or link accounts
  • Lengths and which 8 books in these mockups are samples
