No separate mode. After PDF or file (or Type it), the app already knows whether the file holds pictures. A .pdf, .docx or .txt with only text opens its Pages step with one picture slot per page. Tap a slot to pick that page’s picture, or Pick pictures for all pages to fill the empty slots in file-name order (1, 2 … 10). Pictures are optional, so nothing blocks Next; it goes on to the usual Cover and Text steps.
