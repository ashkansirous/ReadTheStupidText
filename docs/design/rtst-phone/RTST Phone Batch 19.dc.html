Read The Stupid Text · Phone · Batch 19 (Slices 99–101) · Decisions 103–105
A phone app a first-time user can figure out
Two grandparents couldn't find where to start. The main page now holds only the text being read, two big buttons to add text, a simple player and a Settings gear. Adding text is a two-page wizard: take a photo of each page, then check the text (and translate it) before reading. Android and iOS; the Windows tray app is unchanged. Layout never mirrors (Decision 92). Type is larger than the Batch 9 screens throughout.
