# CLAUDE.md — Dino Reader app

Loaded when you work under `src/DinoReader.App`. The pure library is `src/DinoReader.Core`
(own CLAUDE.md); shared platform code is `src/ReadTheStupidText.Mobile.Shared`; MAUI gotchas
are in `src/ReadTheStupidText.Mobile/CLAUDE.md`; its CI target is in `.github/CLAUDE.md`. Windows-head rules are in
`Platforms/Windows/CLAUDE.md`, Debug test hooks in `Testing/CLAUDE.md`. Long incident accounts and reversed
decisions behind these rules: `docs/plan/notes/dino-app-claude-md-history.md` (the verbatim old text).

> **Naming:** the user-facing product display name is **"Dino Book Reader"** (manifest, store listing,
> app title, UI strings, site). Package ids (`uk.sirous.dinoreader`, `AshkanSirous.DinoReader`), namespaces,
> projects, the `.dino` format and the domain `dinoreader.sirous.uk` stay "DinoReader": do not rename those.

**What it is (Batch 10):** a kids' book reader, a second MAUI app sharing `Mobile.Shared` plus Domain/Application/Documents;
`DinoReader.Core` holds the pure dialogue logic. Icons ("Book hug") live in `docs/design/dino-reader/icons/`: copy, never
redraw. Screens are the mocks in `docs/design/dino-reader/` (`Dino Reader v2.dc.html` plus one file per later batch; the
index is that folder's README): read visual values (colours, sizes, copy, layout) from them, never guess, never call
`DesignSync` for them. (Decisions 72-82, `docs/plan/slices/58-67`)

## Data, store, books

- Stories are `AppDataDirectory/stories/<guid>/story.json` via `FileStoryLibrary`, images only through `TryResolveFile`; grown-up pages implement `IGrownUpPage`, app-launched activities are wrapped in `ExternalActivityGuard`; tokens come from `DinoTokens`. (Slice 61: docs/plan/slices/61-gallery-grownup-gate.md)
- **Store books only (Slice 278: docs/plan/slices/278-dino-store-books-only.md).** No wizard, editor, scan/photo/file import, Add pill or machine translation: `StoryTranslator` reads only the book's bundled `Story.Translations`. `OwnBooksCleanup`/`OwnBooksCleanupRun` (single-flight, from `GalleryPage.OnAppearing`, `story.json` deleted last; backup restore runs the same run) is the only deletion path for own books; add no second one. Dino's csproj sets `IncludeSpeechEngines=false` and `IncludeMlKit=false` (passed to the Mobile.Shared reference): Dino's packages carry no ML Kit, sherpa-onnx or onnxruntime (Slice 305: docs/plan/slices/305-dino-package-cleanup-ml-kit-and-sherpa.md).
- **No phone voice (Slice 278 part B).** Nothing reads aloud with a speech engine and nobody picks a voice (`NoSpeechEngineTests` fails on `ISpeechReader`, `IVoicePackService`, `IVoiceModelService`, `VoicePackInstaller` in this project). A book plays its pre-made clips (`StoryVoicing`) and the family's recordings; a piece with no clip and no recording is shown for `PlaybackSteps.BeatMilliseconds`/`SilentBeat` (Core), reports one `premade_audio` fallback (`clip_missing` / `clip_unplayable`) and the read goes on (`ReadingSession.BeginBeat`). The csproj imports neither sherpa packaging props any more (nothing to neutralise on Android and iOS); only the WinML target stays, for the Windows head, which keeps Infrastructure (logging) and so its engine DLLs. `ISpeechReader` is the phone's own voice there (the Debug test hooks resolve one). `dinoreader-android.yml` calls `.github/scripts/check-android-natives.sh <pkg> --none` on all three Dino packages (asserts no sherpa, onnxruntime or ML Kit native is present; Slice 305): keep those calls, never call it without `--none` on a Dino package. `MauiProgram.cs` registers `InertLanguageNotifier` after `AddMobileSharedServices`. Shelf language choices come only from `ShelfAudioPacks`' `InstalledShelfAudio`; no page reads pack folders.
- No book ships in the app (Slice 261: docs/plan/slices/261-dino-no-starters-first-run-book-picker.md): a fresh install has an empty shelf and picks at least `FirstBooks.Minimum` (2) books from the store on `FirstBooksPage`. The library on disk owns the state (`FirstBooks.IsSatisfied`); `FirstBooksGate.Pending` only says the step began. Installs made before keep their four old starters (same ids as store copies; `StarterStories` keeps only the installed flags). The former starters are Debug-only test books in `Resources/Raw/testbooks/`. Never add a book to the app again. Speaker tags read `Name said` or `said Name` with a bare capitalised name, or the caster finds no character. "Export story" is developer-only (`DeveloperMode`). (Slice 91: docs/plan/slices/91-dino-story-packages-and-starters.md)
- A book is content only (Slices 239, 261, 265): never edit `src/`, `tests/` or app files for one; any book change runs only the store upload (`publish-store` stamps the version). Store books live in `content/dino/<stem>/` (`story.md` + `book.json`, `pictures/<n>.jpg`, `titles.json`) with fixed GUID ids (never change one); a text change is a new `story-v<n+1>.dino`, never an overwrite; they follow the speech-tag rule and the all-languages coverage test. Pictures are 896x1200 (3:4), never upscaled (the print-size originals go in `content/dino/<stem>/high-res/`, Git LFS, never packaged or uploaded; Slice 350): run `tools/prepare-story-pictures.ps1` first, never commit unresized originals; `BookBuilder` copies them as-is and fails on a count mismatch. (Slices 102, 119: docs/plan/slices/102-dino-store-ten-stories.md, docs/plan/slices/119-dino-illustrated-three-little-pigs.md)
- Every Dino book carries translations into all eight other languages and `TranslateToMyLanguage = true`; regenerate a book's tables in `content/dino/<stem>/translations/` after editing its text. "My language" is `StoryTranslator.MyLanguage` (reads `LanguageChoice.Current()`), never `CultureInfo.CurrentUICulture`. A store book's titles live in `content/dino/<stem>/titles.json` (a new store book adds no `ShippedTitles` row and edits no app code). (Slices 95, 159: docs/plan/slices/95-dino-translation-works.md, docs/plan/slices/159-dino-everything-in-my-language.md)
- Language rule (Slice 159, Decision 164): when the app language is X every word shown is in X. Strings and number formats come from `AppResources.Culture` (set by `UiCulture.Apply` from the stored pick), never `CurrentUICulture`. `NoHardCodedUiTextTests` fails on a literal word in a text property or alert. (Slice 159)
- "Good Enough" is a picture starter: sources and the proofread `lines.json` in `content/dino/good-enough/`; only caption lines are page text; no back cover. **Reversed 2026-11-10 (Slice 350):** the words painted into pages 1-7 are left over from the removed picture-text (OCR) feature, so Good Enough is redrawn with no text in any picture, and no Dino picture carries painted words; see docs/plan/slices/350-dino-high-res-pictures.md. ## Usage counts

- Every event is a closed-list `UsageEvent` (Core) with one closed `Detail` (`UsageDetail`); `worker/events.ts` `EVENT_RULES` drops anything else. A new event needs a `UsageEventName`, a rule there, a `UsageCounter` call and a test, plus a line in `site/dino/privacy.html` and `STORE.md`; never free text, a title or an install id. Record only through `UsageCounter`. `tools/dino-usage-report.ps1` holds the SQL. (Slice 134: docs/plan/slices/134-dino-usage-events-and-report.md)
- Playback (Slice 250: docs/plan/slices/250-dino-playback-events-and-session-id.md): `ReadingSession.Stop` takes a closed `ReadStopReason` (a test scans for call sites; the Worker needs a matching name); only `StartAtAsync` counts a start; every `read_started` gets exactly one `read_stopped`; `UsageSession` stamps `Session`/`Seq`.
- Listens and played seconds (Slice 288: docs/plan/slices/288-dino-listens-and-listening-time.md): `ListenTally` runs only while audio is heard (`ReadingSession.Audible` via `UsageCounter.SetAudible`); `read_paused`/`read_stopped` carry `Seconds`; `book_listened` fires at 30 s of played time; the intro's demo read is never counted (`DemoReadCounting`).
- Never dispose a `UIFont` from MAUI's `IFontManager` (shared). `Platforms/iOS/Resources/PrivacyInfo.xcprivacy` declares no Device ID for the session id: do not add one. (Slices 244, 250)
