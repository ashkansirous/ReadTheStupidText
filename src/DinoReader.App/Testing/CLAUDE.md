# CLAUDE.md — Dino Reader Debug test hooks

Loaded when you work under `src/DinoReader.App/Testing`. App-wide rules: `../CLAUDE.md`.

- Debug hooks `import-test-book id=<stem|all>` and `test-store mode=ok|slow|stall|offline|status402|status404|status429|status503|off` (the `status*` modes refuse every book download with that status and no body, Slice 357; `TestStore*.cs`; `StoreClient` reads the fixture list and `testbook:` addresses) give a flow books and a picker without the live store; `skip-first-run` puts the four test books on the shelf; `shelf-audio lang=sv` starts a run against the test store's one pack. (Slice 261: docs/plan/slices/261-dino-no-starters-first-run-book-picker.md)
- Slice 360 hooks: `pack-repair mode=advance|tick|open|offline|online|state [id= lang=]` (`DinoTestCommands.ShelfAudio.cs`): `advance` moves the process clock 61 minutes (the hourly retry is due), `tick` runs the hourly pass, `open id=` is the retry made when a book opens, `offline|online` force the reading page's "no internet" state only, `state` writes `[PackRepair] state ...`; the reading page writes `[Reading] sound-state kind=Getting|NoInternet|Failed|None percent=n switch=yes|no`; flows `reading-sound-*.yaml`. `force-pack-failure` also takes `mode=missing` (the store's 404). `remove-audio-pack id= lang=` deletes a shelf book's installed pack (the shelf audio run installs the main language's pack at launch, so the flows delete it before opening the book); logs `HOOK remove-audio-pack ok`.
- Debug hook `force-pack-failure mode=network|corrupt|disk-full|missing|off` makes every `AudioPackStore` download fail that way until `off` (`AudioPackStore.ForcedFailure`, `#if DEBUG`, this process only; `missing` is the store's 404). There is no per-launch failure cap: a flow switches the hook `off` and the next due try succeeds, with no restart. (Slice 310: docs/plan/slices/310-dino-debug-hook-force-pack-failure.md)
- Slice 320 hooks (Debug only, Android broadcast and iOS URL alike through the shared dispatcher): `force-pack-failure mode=stall` hangs a pack download until the person cancels it (`pack-cancel-stalled.yaml`); `corrupt-shelf-order` damages the shelf order file and lists the shelf so the library really reports `shelf_order_unreadable` (`usage-fallback-shelf-order.yaml`); `UsageCounter.Stamp` writes `[Usage] seq=<n> <name> session=<id>` for a count that reached the queue. (Slice 320: docs/plan/slices/320-device-check-tooling-from-2026-11-08-run.md)
- Slice 325 (docs/plan/slices/325-dino-2026-11-08-redesign.md): `enter-grown-up tab=books|store|settings` picks the corner's tab as a tap would; layout markers a flow can expect are `[Redesign] corner tab=... chrome=bar|rail`, `shelf title=full|short|hidden ...`, `store columns=...`, `settings page=... hosted=...`, `onboarding page=... shape=...` and `intro step=... shape=stack|split`.
- Maestro flow expect-log markers must be written with `TestHookLog.Write` (RTST-TEST tag), not `Debug.WriteLine`. (Slice 228: docs/plan/slices/228-dino-grownups-corner-clarity.md)
- A 402 re-plans the shop row to Buy, so a Maestro flow that tests another status on the same row must not share a flow with the 402 case; keep 402 in `.maestro/dino/store-payment-required.yaml`. (Slice 357: docs/plan/slices/357-server-error-messages.md)
